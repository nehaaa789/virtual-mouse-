# Virtual Mouse System

## Overview

Virtual Mouse System is an AI-powered computer vision project that enables users to control their computer mouse using hand gestures instead of a physical mouse.

The project uses OpenCV, MediaPipe, and PyAutoGUI to detect hand landmarks through a webcam and perform cursor movements, clicking, scrolling, and drag-and-drop operations.

## Features

* Real-time hand tracking
* Cursor movement using finger gestures
* Left click and right click
* Scrolling functionality
* Drag and drop support
* Touchless human-computer interaction

## Technologies Used

* Python
* OpenCV
* MediaPipe
* PyAutoGUI
* NumPy

## Applications

* Accessibility solutions
* Touchless computer control
* Human-computer interaction research
* Smart workspace environments
